# VECTOR7: Zero-Trust Claim-Level Credibility Assessment

## Anonymous Repository for Peer Review

This repository contains the core manuscript, the operational training framework, and the raw experimental artifacts for the **VECTOR7** methodology. VECTOR7 is a zero-trust, claim-level credibility assessment framework designed to evaluate the epistemic robustness of Conversational AI models without requiring access to authoritative ground truth or model internals.

This repository is completely anonymized in accordance with double-blind peer-review guidelines. 

---

## 📁 Repository Contents

This repository contains the following three foundational documents. Please refer to them for the complete algorithms, curricula, and raw data outputs.

### 1. `ACM_SAC_Vector7_v9.pdf`
**Primary Manuscript: "VECTOR7: Zero-Trust Claim-Level Credibility Assessment for Conversational AI"**
This document outlines the core theoretical framework and algorithms of VECTOR7.
*   **The 7-Probe Signature:** Details the seven orthogonal verification strategies: Procedural Detail (V1), Circumstantial Consistency (V2), Task/Falsification (V3), Linguistic Invariance (V4), Context/Transfer (V5), External Evidence (V6), and Self-Audit (V7).
*   **Algorithms:** Defines the VECTOR7 Cross-Probe Consistency Conditioning (V7-CPCC) and the Epistemic Decision Algorithm (V7-EDA).
*   **Quantitative Metrics:** Introduces Claim Epistemic Strength (CES), Claim Coverage Mass (CCM), and Claim Epistemic Entropy (CEE).
*   **Case Study:** Application of the framework on 9 self-reported transparency claims generated by two frontier-class models (Gemini 3 Flash and DeepSeek V3.2).

### 2. `TR2026-VECTOR7.COMPETE-KP.pdf`
**Supplementary Framework: "VECTOR7.COMPETE: A MODEL-PROBING COMPETENCY FRAMEWORK FOR ADVERSARIAL AI-RESILIENT CYBER ANALYST"**
This document translates the theoretical VECTOR7 framework into an actionable, DCWF-aligned (Department of Defense Cyber Workforce Framework) training architecture.
*   **10 Core Competencies:** Outlines the analytical pipeline for cyber analysts: DOUBT, ATOMIZE, GROUND, CHALLENGE, TRANSFER, ANCHOR, ANALYZE, CROSSCHECK, ADJUDICATE, and VERIFY.
*   **10-Week "Experience Room" Curriculum:** A tiered syllabus moving learners from foundational epistemic literacy (identifying "Synthetic Authority") to specialized DoD mission tasks (Secure DevSecOps, Threat Intel Integrity), culminating in a live-fire strategic adjudication exercise.
*   **The Verification Passport:** A digital micro-credential architecture designed to replace resume-based hiring with performance-based placement, demonstrating a candidate's quantified Human Over-Trust Rate (HOTR) reduction.

### 3. `TR2026-VECTOR7-ChatbotResponses.pdf`
**Experimental Data: "Chatbot Responses: VECTOR7: Zero-Trust Claim-Level Credibility Assessment for Conversational AI Models"**
This document serves as the raw data artifact and reproducibility benchmark for the case study presented in the main manuscript.
*   **Interrogation Prompt Set:** The exact wording of the 63 prompts (7 probes applied across 9 distinct transparency claims) utilized during the evaluation.
*   **Unedited Transcripts:** Full, unedited responses from Gemini 3 Flash and DeepSeek V3.2 demonstrating semantic drift, refusal-compliance asymmetries, and evidentiary hallucinations under adversarial interrogation.
